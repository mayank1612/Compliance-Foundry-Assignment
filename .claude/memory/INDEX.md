# Shared runbooks

Team-owned, git-tracked notes for working on this codebase. Loaded into every
Claude Code session via `CLAUDE.md`. Add pointers here (one line each) - keep
the full detail in the linked file to keep the context budget lean.
New entries normally come from the `learn` skill
(`.claude/skills/learn/SKILL.md`), which also strengthens an entry when its
rule gets broken again. How a specific feature works belongs in
`docs/features/`, not here.

- [Code comments are mandatory](./feedback_code_comments_mandatory.md) - every
  new or modified line/block must carry detailed comments covering the
  relevant what / why / which / where / how / when / who dimensions.
